Project Overview

In building this full stack web application, I worked with multiple types of frontend development. Express HTML and JavaScript provided the foundation for rendering pages and handling basic interactions, while the single‑page application approach allowed for a smoother, more dynamic user experience without constant page reloads. On the backend, I used a NoSQL MongoDB database because of its flexibility in handling unstructured data and its ability to scale easily with user and administrative needs. This combination of technologies created a system that could serve both customers and administrators effectively.

Functionality was tied together through JSON, which differs from JavaScript in that it is a lightweight data format rather than a programming language. JSON acted as the bridge between the frontend and backend, allowing data to be exchanged consistently across the application. During development, I refactored code to improve efficiency, such as consolidating repeated logic into reusable UI components. These components not only reduced redundancy but also made the application easier to maintain and expand, ensuring a more polished and professional product.

Testing was an important part of the process, especially when working with API endpoints and adding security features for admin login. I tested methods for both request and retrieval to confirm that data was being handled correctly, and I accounted for the added complexity of secure authentication by validating that only authorized users could access administrative features. Reflecting on the course, I’ve gained valuable skills in full stack development, including database integration, API design, and secure authentication practices. These experiences have strengthened my ability to approach problems like a computer scientist by breaking them down, designing scalable solutions, and considering ethical responsibilities to both users and organizations. Altogether, this project has made me more confident and marketable as I move forward in my career.
